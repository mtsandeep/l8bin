01 · Setup

Zero to agent-driven.

1

Setup LiteBin

once, on any VPS with Docker

Already running LiteBin? Skip ahead, this step isn't for you.

curl -fsSL https://l8b.in | bash

Fresh install? Create the first admin account when the installer finishes (the quickstart walks the prompts).

2

Set up litebin mcp

your agent
setup litebin mcp from l8bin.com

The agent takes it from here. It installs the l8b CLI if it's missing, asks for your server URL, runs the pairing, and hands you an approval link. Open it, pick the scope, approve.

rather run it yourself?

curl -fsSL https://l8b.in | bash -s cli
l8b login --server https://l8bin.example.com --pair
3

Wire the repo

l8b init --mcp
  • ✔Writes l8b.toml + .mcp.json: Claude Code, Cursor and ZCode pick the tools up on next open
  • ✔Codex: codex mcp add l8bin -- npx -y l8bin-mcp
  • ✔Other clients: any stdio entry with command npx, args ["-y", "l8bin-mcp"]
  • ✔Agents that don't speak MCP: the AGENTS.md template

that's the whole setup · from here it's conversation ↓
